# 気持ち番頭（デモ）

株式会社気持ち市場の商品「気持ち番頭」の、さわれるデモです。

**https://kimochiichiba-netizen.github.io/kimochi-banto-demo/**

夜のうちにAIが事務の下書きを作り、朝、押すだけで終わる仕組みを、実際に触って確かめられます。

## 使い方

右上の「業種をえらぶ」で11業種が入れ替わります。画面の呼び名も、その業種の言葉に変わります。

商談前に相手の業種で開いておくときは、URLの後ろにつけてください。

- `#box/yasai` 青果・食品卸 ／ `#box/kensetsu` 建設・工務店 ／ `#box/seikotsu` 整骨院・接骨院
- `#box/kaigo` 介護事業所 ／ `#box/clinic` クリニック・歯科 ／ `#box/inshoku` 飲食店
- `#box/biyo` 美容室・サロン ／ `#box/shigyo` 士業 ／ `#box/ec` 小売・EC
- `#box/seizo` 製造・町工場 ／ `#box/unso` 運送・軽貨物

画面は5枚です。`#box` 承認箱 ／ `#pipes` 受け口 ／ `#report` 今月の1枚 ／ `#setup` 設定 ／ `#ask` 聞く

文字が小さいと感じたら、右上の「らくらく表示」を押してください。文字とボタンが大きくなります。

## お断り

- これはデモです。押しても、メールが送られたり、お金が動いたりすることはありません。
- **画面に出ている会社名・お名前・金額・件数・時間の数字は、すべて架空のサンプル値です。** 当社の実測値でも、どこかのお客様の実績でもありません。
- **導入実績は0社です。効果は保証しません。**
- AIの処理は米国のAnthropic社へ送信されます。手書き・FAXの読み取りだけは、お使いのパソコンの中で完結します。
- 承認箱の本体・受け口の実接続・SNSの予約公開は、まだ作っていません（今後の開発項目です）。
