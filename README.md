# 気持ち番頭（デモ）

株式会社気持ち市場の商品「気持ち番頭」の、さわれるデモです。

**https://kimochiichiba-netizen.github.io/kimochi-banto-demo/**

夜のうちにAIが事務の下書きを作り、朝、押すだけで終わる仕組みを、実際に触って確かめられます。

## 何が入っているか

左のメニューは、**最初は6つだけ**出ています。機能は48ありますが、全部を最初から見せると「何から使えばいいか分からない」になるためです。

**毎日つかう（6つ）** — 今日の承認箱／番頭にできること／昨日やったこと／毎月の決まりごと／お金の見張り番／ダッシュボード

残りは、必要になったときに開いてください。

- **そのほかの機能（20）** — 番頭の任せ方／番頭に教える／番頭（経営参謀AI）／週次レポート／経営レポート定期便／コスト削減シミュレーター／導入のしかた／社長専用の相談／案件・アポ管理／タスク／日報／シフト／収支・月次／請求・入金／資金繰り／書類プレビュー／削減メーター／補助金斡旋／専属AI記憶ノート／通知連携
- **AI社員の6分野（5）** — 社内の決まりごと係／電話・問い合わせ番／受付・ご案内／商談の下ごしらえ／採用の受付係
  （残る1つ「経理・バックオフィス」は「今日の承認箱」と「請求・入金」がそれにあたります）
- **オプション（17・別料金）** — 押すと、その機能のミニデモが開きます

はじめに見ていただきたいのは **「番頭にできること」** です。世の中で「AI社員」と呼ばれている6つの分野それぞれについて、**今できること／人が押すところ／まだできないこと** の3つに分けて書いてあります。

### とくに見ていただきたい3つ

| 画面 | 中身 |
|---|---|
| **番頭の任せ方** | どこまで自動にするかを、仕事ごとに4段階（任せない／口出しだけ／確認モード／おまかせ）で決めます。**おまかせにできるのは、社長が先に文を決めたものだけ**です。お金が動くもの・初めての相手に出るものは、設定でも「おまかせ」にできません |
| **お金の見張り番** | 払う前に「いつもと違う所」だけをお知らせします。**振込先の口座が前回と違う（口座のすり替えよけ）／同じ請求書が2枚ある（二重払いよけ）／消費税の区分が違う** など |
| **昨日やったこと** | 押さなくても通したものと、おまかせで出したものの記録。**1つずつ取り消せます**。自動で通したものを見えない所に置くと、何が起きているか分からなくなるためです |

### 承認箱の札にあるもの

- **自信のしるし** — 「たしか／たぶん／自信なし」の3語。数字（87%など）では出しません
- **いつまでに押すか** — 期限が過ぎても、番頭が勝手に実行することはありません
- **押す選択肢は4つ** — そのまま通す／直して通す／ひとこと返す／今日は見送る。2択にすると「とりあえず通す」しか道がなくなります
- **押したあと15秒は取り消せます**
- **足あと3行** — 2行目は「できなかったこと」。読めなかった／見つからなかった／人が決めること、の印が付きます

## 使い方

- **業種の切り替え**：「今日の承認箱」の上にあるボタンで、11業種が入れ替わります。画面の呼び名も、その業種の言葉に変わります。
  （青果・食品卸／建設・工務店・リフォーム／整骨院・接骨院／介護事業所／歯科医院／飲食店／美容室・サロン／士業／小売・EC／製造・町工場／運送・軽貨物）
- **1件ずつ見る**：承認箱の「1件ずつ見る」を押すと、1画面に1件だけ出ます。進み具合がバーで分かります。
- **従業員の画面**：左下の「従業員画面に切り替え」で、従業員から見た画面になります。お金と全社の数字は出ません。管理者に戻すときは、本番ではパスワードが要ります（このデモでは空のまま入れます）。

## お断り

- これはデモです。押しても、メールが送られたり、お金が動いたりすることはありません。
- **画面に出ている会社名・お名前・金額・件数・時間の数字は、すべて架空のサンプル値です。** 当社の実測値でも、どこかのお客様の実績でもありません。
- **導入実績は0社です。効果は業務により異なり、お約束はできません。**
- **画面の裏側は、まだつながっていません。** 会計ソフト・銀行・チャット・予約システムへの接続は、これからの開発項目です。今のデモは、すべて用意したサンプルを表示しています。
- 当社の環境で本当に動いているのは、事務の20の係（銀行明細と請求台帳の照合、カード明細の仕分け、適格請求書の作成と検算、給与明細の作成と検算、手書き・FAXの読み取り、録画からの手順書づくり）です。お客様の会社ごとの構築は、これからです。
- AIの処理は米国のAnthropic社へ送信されます。手書き・FAXの読み取りと、録画の声の文字起こしだけは、お使いのパソコンの中で完結します。
- 承認箱の本体・受け口の実接続・SNSの予約公開は、まだ作っていません。
